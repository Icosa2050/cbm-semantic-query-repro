# Architecture

## Overview

A parcel delivery backend split into three independent domains.

## Pricing Domain

Tariffs, bulk discounts, and cross-border currency surcharges.

## Telemetry Domain

Vehicle battery charge, cold-chain cabin temperature, tyre pressure alarms.

## Routing Domain

Waypoint graph, great-circle distances, Dijkstra route selection.
